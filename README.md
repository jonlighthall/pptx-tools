# pptx-tools

Utilities for working with PowerPoint files and slide decks.

## Contents

- `extract_outline.py` — Extract a markdown outline from a `.pptx` file.

## Setup

### 1. Create a Python virtual environment (first time only)

```bash
python3 -m venv ~/venvs/pptx-tools
source ~/venvs/pptx-tools/bin/activate
python -m pip install --upgrade pip
python -m pip install python-pptx
